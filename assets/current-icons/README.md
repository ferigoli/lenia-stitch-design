# Current LENIA icons

These SVGs are based only on the CURRENT approved LENIA screens.

They are intended as a reusable visual vocabulary for Google Stitch and later Figma/Flutter implementation.

Use:
- `currentColor` for line color
- Light theme: deep navy / violet accents
- Dark theme: pale lavender / white / violet accents

Do not replace them with a different icon family unless a current approved screen explicitly changes the icon.
