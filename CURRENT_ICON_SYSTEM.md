# LENIA — Current icon system

Source of truth: the 18 CURRENT approved screen references supplied on 2026-09-24.

This library intentionally excludes the obsolete historical mockup set.

## Style
- 24×24 SVG viewBox unless noted
- rounded stroke caps and joins
- stroke width 1.8
- no hard-coded theme color: icons inherit `currentColor`
- use the LENIA violet/indigo palette at component level
- Light and Dark use the SAME icon geometry; only color/glow/container treatment changes
